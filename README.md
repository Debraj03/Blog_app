Project 2: Simple Blog API
Stack: Django REST Framework or FastAPI
Requirements:


Endpoints for:


Create, list, update, delete blog posts.


Each post has title, content, author, created_at.



Add user authentication (JWT or Django auth).


Only authors can edit/delete their posts.


Bonus: Add comments API for each post.


What it tests:


Authentication & authorization.


REST API best practices.


Relational models (posts ↔ comments).
